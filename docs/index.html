A semi-serious benchmark

Can AI survive a
Bengaluru quiz?

MulkiMark puts AI models through real quizzes set by the Karnataka Quiz Association, the people behind Mahaquizzer. These are not multiple-choice exams. Each question is a small puzzle of clues, and you get there by connecting a Kannada film, a 1937 magazine article and a Scottish farm.

Same paper as the humans

Every model answers the full written quiz, one question at a time, with no web search and no second chances.

Same rules as the humans

Marked against the official answer key. A correct surname will do; a wrong first name will not.

The questions stay secret

The questions belong to their quizmasters, so we only publish the scores.

How it works

  1. 01

    The paper

    We use the full question set of each quiz, exactly as it was handed to the human contestants.

  2. 02

    The attempt

    Each model sees one question at a time and gives a single answer. No tools, no browsing, no hints.

  3. 03

    The marking

    Answers are checked by hand against the official key, using the quiz's own rules on spellings and surnames.

  4. 04

    The verdict

    Scores are tallied by quiz and by subject. Ties stay ties. Nobody gets to appeal to the quizmaster.
